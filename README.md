# Keep Out

G1 Concept Pitch — COMS E6998, Fall 2026

Keep Out is a dungeon-defense strategy game where players arrange traps to stop an adventurer from stealing their treasure. The initial proposal covers one map, one adventurer and five rounds of building, observing and revising.
